# Версионирование Finam-client

Semver, тег `vX.Y.Z` на `develop`, в `main` попадает при `run/release.sh publish`.
Канон версии — файл `VERSION`; `run/version.sh` держит в синхроне ещё
`pyproject.toml` и `finam_client/version.py` (проверка — `run/check-version.sh`).

| Уровень | Когда |
|---------|-------|
| **PATCH** | Исправления, доки, тесты; расширение таблицы `finam_client.venue` подтверждёнными парами |
| **MINOR** | Обновление proto брокера без ломки публичного API; новые методы клиента, поля нейтральных моделей, новые модули |
| **MAJOR** | Несовместимое изменение публичного API клиента (сигнатуры, удаление методов/полей, смена типа ошибок). Поднимается только по явному решению владельца |

Потребители (AFB, BF) пинят `@develop`; тегированный релиз нужен для воспроизводимых
образов (`build.sh push` берёт `main`).

Записи об изменениях — в `CHANGELOG.md` под `## Unreleased` по ходу работы, без версии;
`run/version.sh` оформит секцию под релиз.
